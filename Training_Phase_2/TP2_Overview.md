Information about the Training_Phase_2 Directory:

Includes all the files pertaining to the second training phase of the experiment, including:
- Videos of the characters Chloe and Chris
- Images presented to the participant
- JavaScript code for use on the PCIbex farm
- CSV file used by the code to generate trials
- Script for the characters' responses and interactions

Elements absent from this directory that are still used in the training phase trials include the green button animation and red button animation.
The participant will select one of the buttons to indicate "yes" or "no", respectively.
These video animations can be found in "Buttons" which is available as a separate folder in the main branch.

Information about Training Phase 2:

Training Phase 2 is meant to prepare the participant for the tasks in the Test Phase, such that the Test Phase is able to achieve its purpose (of testing if the participant has learned the speaker's preferences) effectively.

It contains an introduction and conclusion from the cartoon character Chloe to explain the task, and to provide instructions for the task. The conclusion provides a transition to the next phase, and reiterates the instructions to the participant for the test phase.

It contains only 1 trial due to the long duration of each trial contrasted with the short attention of the participant. It follows the format of the trials/tasks in the test phase:
- It introduces the participant to the concealment of a word in the speaker's description of the image printed onto the screen using white noise.
- Here, the participant's mission is to determine the identity of the concealed word from the options provided below in the form of three buttons (one circle, one square, one triangle). Of the three buttons, one will represent the right answer, one an alternate response, and one "not sure".  
The image used in the trial is of strawberries in a bowl, with "strawberries" being the concealed word. The alternative response is "blueberries".

The media files available in the For_extra_trials folder are used to build extra trials for this training phase, if one appears to be insufficient, or simply if these alternative trials seem to offer potentially better training for the participant. Currently, they are already incorporated into the CSV file used by the Template function of the PCIbex code to generate trials.
